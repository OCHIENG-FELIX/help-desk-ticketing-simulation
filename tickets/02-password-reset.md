# Ticket 002: Password Reset Request

## Ticket Information
- Ticket ID: HD-002
- Category: Account Management
- Type: Service Request
- Priority: P4 - Low (Illustrative)
- Assigned Team: IT Support L1
- Status: Completed (Simulated)

## User Report
A user requests assistance resetting an account password.

## Initial Investigation
- Verify the user's identity using approved procedures.
- Confirm the affected account.
- Check whether the account is locked.
- Determine whether a password reset is authorized.

## Possible Resolution
Perform the password reset through an approved identity management process.

## Security Considerations
- Never ask the user to disclose their existing password.
- Never send passwords through insecure communication channels.
- Follow the organization's identity verification requirements.
- Require an approved password change process.

## Verification
Confirm that the user can authenticate successfully without requesting or viewing their password.

## Closure Notes
The simulated request is completed and documented.

## Lessons Learned
Account management must balance efficient support with strong identity verification and security controls.
