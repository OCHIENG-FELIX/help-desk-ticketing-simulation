# Ticket 005: Printer Not Working

## Ticket Information
- Ticket ID: HD-005
- Category: Hardware / Peripheral
- Type: Incident
- Priority: P3 - Medium (Illustrative)
- Assigned Team: IT Support L1
- Status: Resolved (Simulated)

## User Report
A user reports that the office printer is not printing documents.

## Initial Investigation
- Check printer power and status.
- Inspect cable or network connection.
- Confirm the correct printer is selected.
- Review the print queue.
- Check for paper or toner errors.
- Inspect printer driver status.

## Possible Cause
A stuck print job or temporary printer connection issue.

## Simulated Resolution
Clear the stuck print job after confirming it is safe to do so, then retry printing.

## Verification
Print a test page and confirm successful output.

## Closure Notes
The user confirms that printing has resumed.

## Lessons Learned
Basic peripheral checks can resolve many common printer incidents.
